# Rust Installation



##### Disclaimer:

This is an installation guide for Windows 10/11 only as that is the OS I am using to code in Rust, for documentation and information regarding the installation of Rust on other OS, you may find it [here](https://forge.rust-lang.org/infra/other-installation-methods.html).



##### Installation: 

To code in Rust, we must have rustup installed, which you can visit [here](https://rust-lang.org). We will also need to have our IDE [Visual Studio Code](https://code.visualstudio.com) (VSC) installed if it isn't already, as well as the [Visual Studio Installer](https://visualstudio.microsoft.com/downloads/) (VSI)



##### Extensions:

In order for our code to run, we need to download a few extensions. Firstly, upon installing VSI, in the workload tab we need to install the "Desktop Development with C++" workload, after installation you may close VSI. Finally, in VSC, in the extensions tab, we need install the following; [core rust extensions](https://marketplace.visualstudio.com/items?itemName=1YiB.rust-bundle), [C/C++](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools), and [CMake](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cmake-tools). Once all these steps have been completed, you can create a Hello World program to check if rust is working correctly on your computer.
